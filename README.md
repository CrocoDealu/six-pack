# 30 Day Abs

A mobile-first static site for a 30-day abs plan. Three workout days, then a rest day, repeating (rest on days 4, 8, 12, 16, 20, 24, 28).

- Pick a start date once. It is saved in the browser's localStorage and the current day is computed from it.
- `exercises.json` holds every workout day's exercises (reps or seconds) and the photo for each.
- `photos/` holds one thumbnail per exercise.

Hosted with GitHub Pages from the `main` branch root.
